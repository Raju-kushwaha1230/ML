# Data Collection and Machine Learning Overview

## Data Collection Methods
- **API Data Collection**: Fetch structured data from REST APIs or other web services.
- **Web Scraping**: Extract data from websites using scraping tools and parsers.
- **CSV Files**: Load tabular data from `.csv` files for analysis and modeling.
- **JSON Files**: Read semi-structured data from `.json` files.
- **SQL Databases**: Query relational databases using SQL to collect training data.
